# Text Similarity Checker

A simple Python project that measures how similar two text inputs are using TF-IDF and Cosine Similarity.

## How It Works

1. Takes two text inputs from the user.
2. Converts the texts into TF-IDF vectors.
3. Calculates the Cosine Similarity between the vectors.
4. Displays the similarity score as a percentage.

## Technologies Used

- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity
